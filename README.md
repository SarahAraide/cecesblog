# CECE · the magazine for a stacked life

**Live site:** https://saraharaide.github.io/cecesblog/
**Repository:** https://github.com/SarahAraide/cecesblog

CECE is a messy, Y2K pink, collage-style online magazine about my life as a
writer, Mechanical Engineering student at the Technion and tutor. It opens like
a printed issue: a one-screen cover (an open magazine with a Contents page on
wide screens), then story pages you can flip through like real pages.

## What's inside

| Page | What it is |
| --- | --- |
| Cover (`index.html`) | Chrome cover with clickable cover lines, a Contents page, and dark mode ("Midnight Issue") |
| The Writer's Room | My debut poetry book *Cece Once Said*, two poems and a short-story reading list |
| Cece's Kitchen | My pink ladybug cheesecake recipe, plus credited links to recipes I love |
| Movie Night | 210 films and shows sorted by mood, with mood buttons, a Films/Series filter and a search box |
| Legally Blonde Labs | My research interests and engineering projects |
| Study Hall | A shelf of notebooks, one per course, with my own notes and labelled AI-assisted summaries |
| Cat of the Month | TayTay, the cover cat |
| Sale Alert | My favourite stores and whether they're on sale |
| Mind Matters | Mental-health awareness projects I worked on, and where to find support |
| The Puzzle Page | A playable sudoku that makes a new puzzle every time |

## Features

- Plain **HTML, CSS and JavaScript**: no frameworks and no build step
- Works on phones, tablets and laptops (the cover turns into one column on phones)
- Light and dark mode, remembered between visits
- "Turn the page" navigation, plus the ← and → arrow keys, to flip between stories
- Accessible: keyboard friendly, screen-reader labels, good colour contrast,
  and less animation for people who ask their device for reduced motion
- Share previews (Open Graph) and a custom 404 page

## Tools I used

- **VS Code**: writing and previewing the code
- **GitHub Copilot**: code suggestions while typing
- **Claude Code**: an AI assistant that helped plan, build and check the site
- **GitHub Pages**: free hosting for the live site
- Google Fonts: Bagel Fat One, Fredoka, Gochi Hand and Nunito
