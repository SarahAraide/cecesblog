# images/

Put your VSCO photos in this folder using **exactly** these file names.
The site already points to them. Until a file is here, its spot shows a
"photo coming soon" placeholder, and the moment you add it the photo appears.
You don't need to change any code.

| File name | Where it appears |
| --- | --- |
| `cover-cece.jpg` | Front cover: the big cover photo of you |
| `book-cover.jpg` | The Writer's Room: your book cover |
| `writing-desk.jpg` | The Writer's Room |
| `baking-1.jpg` | Cece's Kitchen: recipe card 1 |

## Tips

- **Lowercase, hyphens, `.jpg`.** `Cats-1.JPG` or `cats 1.jpg` will NOT work
  on GitHub Pages. Windows doesn't care about upper/lowercase, but GitHub Pages does.
- **Shrink big photos** to about 1200px wide before adding them, so pages load fast.
- **Update the alt text** in the HTML to describe what's actually in each photo
  (search the HTML for `TODO (Cece)`).

## decor/

CD, flip phone, circuit lines) used as decoration. You don't need to touch these.
