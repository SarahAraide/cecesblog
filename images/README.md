## Tips

- **Lowercase, hyphens, `.jpg`.** `Cats-1.JPG` or `cats 1.jpg` will NOT work
  on GitHub Pages. Windows doesn't care about upper/lowercase, but GitHub Pages does.
- **Shrink big photos** to about 1200px wide before adding them, so pages load fast.
- **Update the alt text** in the HTML to describe what's actually in each photo.
